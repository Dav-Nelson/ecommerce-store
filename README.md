# ShopNaija
Full-stack e-commerce store built with PERN stack.

## Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: Express + Node.js + PostgreSQL
- Database: Neon
- Authentication: JWT

## Setup
1. Clone repo
2. Setup environment variables based on `.env.example`
3. Run `npm install` in /server and /client
4. Run servers
